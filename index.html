THE APPROACH

        
One binary. Instant start. Key-optional.

        
Aether is a single static Rust binary — no Node runtime, no bundled browser, no interpreter overhead. It starts in milliseconds and sips RAM.

      

      

        

          
One static binary

          
Compiled Rust, not interpreted. No Node.js, no registry, no dependency tree — just a binary that runs where you tell it to. Windows, macOS, Linux.

        

        

          
Starts in milliseconds

          
No JIT warm-up, no interpreter boot, no package loader. aether is ready before your shell prints the next prompt — and it idles in tens of MB, not hundreds.

        

        

          
No key, no problem

          
Ships with the free Zen provider — no API key, no account. Bring your own key only when you want a different model.

03

          
Light on RAM

          
A native Rust binary idles in tens of MB — not hundreds. No Electron, no bundled Chromium, no interpreter overhead. Your RAM belongs to your tools.

        

        

          
04

          
Sessions

          
Every chat auto-titles and saves. Browse, resume, or delete with aether sessions. On the roadmap — shipping next.

        

        

          
05

          
Recall

          
Cross-session memory: search every past conversation with aether recall "phrase" and jump straight back in. On the roadmap.

        

        

          
06

          
MCP tools

          
Connect any Model Context Protocol server and let tools join every turn. On the roadmap.

        

        

          
07

          
Cross-platform

          
Windows, macOS, and Linux — one binary per platform, x86 and ARM. No browser, no sandbox, no platform-specific installers.

        

        

          
08

          
Sync across devices

          
Point aether sync setup at a private GitHub gist or any synced folder (Dropbox, Drive, Nextcloud, Syncthing), then push and pull. Continue on another machine where you left off — no account, no subscription. On the roadmap.
