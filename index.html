THE APPROACH

        
Terminal-native. RAM-light. Key-optional.

        
Aether is a Node CLI with a lightweight Ink terminal interface — no Electron, no bundled browser, no bloated TUI framework. It starts fast, streams light, and runs anywhere Node does.

      

      

        

          
Runs in any terminal

          
Windows Terminal, iTerm2, GNOME Terminal, VS Code's integrated panel — if it has a shell, Aether works in it.

        

        

          
Sips RAM

          
One Node process, no Electron shell, no embedded browser. The default Ink UI stays lean, and the readline REPL path is even lighter when you stream into a non-TTY.

        

        

          
No key, no problem

          
Ships with the free OpenCode Zen provider. Bring your own key only when you want a different model.

        

      

    


    

      

        
FEATURES

        
Everything a coding agent should be.

        
Built for the terminal, tuned for low RAM, honest about providers.

      

      

        

          
01

          
Zero setup

          
Ships with the free OpenCode Zen provider — OpenAI-compatible, no API key. Run aether and start chatting.

        

        

          
02

          
8+ providers

          
zen, openai, anthropic, google, deepseek, openrouter, ollama, and any custom OpenAI-compatible endpoint.

        

        

          
03

          
Swarm subagents

          
Decompose any task and run parallel subagents with aether swarm "task".

        

        

          
04

          
Sessions

          
Every chat auto-saves with a title. Browse, resume, or delete with aether sessions — or /resume inside the REPL. Total token usage: aether stats.

        

        

          
05

          
Light on RAM

          
A Node CLI with a lightweight Ink terminal UI — no Electron, no browser, no bundled Chromium. A session idles in the tens of MB, not hundreds, and set AETHER_NO_TUI=1 for the leanest readline REPL.

        

        

          
06

          
MCP tools

          
Connect any Model Context Protocol server in ~/.config/aether/mcp.json — the tools join every turn automatically. List them with /mcp.

        

        

          
07

          
Recall

          
Cross-session memory: search every past conversation with aether recall "phrase" (or /recall) and jump straight back into the hit. The medium between stars — your agent remembers.

        

        

          
08

          
Cross-platform

          
Windows, macOS, and Linux from the start. One Node CLI with a terminal-native UI — no browser, no sandbox, no platform-specific installers.
